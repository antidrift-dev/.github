# antidrift

Open source tools, built because [probeo](https://probeo.io) needed them first. MIT licensed.

## ZeroMCP

**[zeromcp](https://github.com/antidrift-dev/zeromcp)**: zero-config MCP runtime. Drop a tool, get a sandboxed MCP server. [Docs](https://github.com/antidrift-dev/zeromcp/blob/main/docs/README.md) · [Benchmarks](https://github.com/antidrift-dev/zeromcp-benchmarks)

The same runtime comes in ten languages:
[Node](https://github.com/antidrift-dev/zeromcp-node) ·
[Python](https://github.com/antidrift-dev/zeromcp-python) ·
[Go](https://github.com/antidrift-dev/zeromcp-go) ·
[Rust](https://github.com/antidrift-dev/zeromcp-rust) ·
[Java](https://github.com/antidrift-dev/zeromcp-java) ·
[Kotlin](https://github.com/antidrift-dev/zeromcp-kotlin) ·
[C#](https://github.com/antidrift-dev/zeromcp-csharp) ·
[Ruby](https://github.com/antidrift-dev/zeromcp-ruby) ·
[PHP](https://github.com/antidrift-dev/zeromcp-php) ·
[Swift](https://github.com/antidrift-dev/zeromcp-swift)

Each language repo is a read-only split of the main repo.
